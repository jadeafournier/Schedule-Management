Schedule Management Program - Windows Release
=============================================

Requirements:
- MySQL must be running (e.g. via XAMPP)

First-time setup:
1. Copy .env.example to .env in this folder
2. Edit .env if your MySQL username/password differs from the defaults

Run:
- Double-click ScheduleManagement.exe
- Your browser will open to http://localhost:5000

Files in this folder:
- ScheduleManagement.exe  - the application (includes Node.js and server)
- .env                    - your database settings (create from .env.example)
